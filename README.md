# Foggy Oracles
Foggy Oracles provides decentralized and verifiable weather oracles for on-chain protocols.
## About
Smart contracts are not aware of what happens outside blockchain boundaries. Foggy Oracles bridges that gap so on-chain applications can react to weather-related events with reliable, real-world data.
Built on top of WeatherXM's decentralized weather station network, Foggy Oracles delivers data that is accurate, transparent, and resistant to tampering.
## Network footprint
- 5,000+ weather stations
- 70+ countries covered
- Hyper-local weather measurements from the WeatherXM network
## Why use Foggy Oracles
- **Precise weather data:** access granular weather observations for your dApp and protocol logic.
- **Available worldwide:** broad global coverage across many regions and climates.
- **Reliable & tamper-proof:** cryptographic guarantees support trustworthy oracle delivery.
- **Decentralized & transparent:** weather data comes from a decentralized network, reducing centralized control risks.
- **Accessible data:** unlock data availability in regions with limited conventional weather infrastructure.
- **Economic benefits:** more accurate weather inputs improve decisions and reduce risk for weather-sensitive on-chain use cases.
